# Mobile Developer → Frontend Web — Role Profile

> For iOS/Android/React Native engineers who want to expand into frontend web roles.

## Transferable Skills
| Mobile Skill | Frontend Equivalent |
|-------------|-------------------|
| React Native + TypeScript | React.js + TypeScript |
| SwiftUI / Jetpack Compose (declarative) | React (declarative UI) |
| State management (Redux, MobX) | Same libraries on web |
| REST API / gRPC integration | REST API / GraphQL |
| App performance optimization | Web performance (Core Vitals) |
| Firebase Analytics/Crashlytics | Sentry, Google Analytics |
| CI/CD (Fastlane, Bitrise) | CI/CD (GitHub Actions, Vercel) |
| App Store / Play Store | Web deployment (Vercel, AWS) |

## How to Position on CV

Frame mobile experience as UI/UX engineering with performance focus:

- "Built high-performance UI applications using React/TypeScript serving 58K+ monthly active users"
- "Optimized application launch time by 32% through code splitting and lazy loading"
- "Implemented responsive, accessible interfaces with component-based architecture"
- "Maintained 99.87% crash-free rate through proactive monitoring and error boundary implementation"

## Suggested CV Bullet Points
- Developed component-based UI applications using React and TypeScript, serving 58K+ monthly active users across multiple markets
- Optimized application performance achieving 271ms load time — 32% below target — through code splitting, lazy loading, and efficient state management
- Built responsive layouts supporting multiple screen sizes and device types with pixel-perfect implementation
- Integrated RESTful APIs and managed client-side state with Redux/MobX patterns for complex e-commerce workflows
- Implemented comprehensive error monitoring with Sentry and Firebase, maintaining 99.87% stability rate
